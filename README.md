# 🎨 AI-Based Black & White Image Colorization

## 📌 Project Overview

Black and white images lack visual realism and emotional depth due to the absence of color information. Manually colorizing such images is time-consuming and requires artistic expertise.

This project presents an **AI-based Deep Learning system** that automatically colorizes grayscale images using **Convolutional Neural Networks (CNNs)**. The model learns color patterns from large image datasets and generates realistic colorized outputs with minimal human intervention.

---

## 🎯 Objectives

* Automatically convert black & white images into color images
* Reduce manual effort and time required for image colorization
* Apply Deep Learning techniques to learn color representations
* Demonstrate practical usage of CNNs in computer vision

---

## 🧠 Deep Learning Approach

* Input grayscale image is processed through a CNN model
* The network learns spatial and color features from training data
* Predicted color channels are combined with the grayscale image
* Final output is a realistically colorized image
